# بدأت إزاي؟ · How I Started

Real, honest starting stories from entrepreneurs in Egypt: how much money they had, where it came from, and how long it took to make the first revenue and the first profit.

A mobile-first, installable web app (PWA) in Arabic and English. Non-profit, open project.

**Status:** early prototype. Project decisions live in [AGENTS.md](AGENTS.md).

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173/how-i-started/

## Scripts

- `npm run dev` start the dev server
- `npm test` run the tests
- `npm run check` lint and format check (Biome)
- `npm run build` production build into `dist/`

Every push to `main` deploys to GitHub Pages.
